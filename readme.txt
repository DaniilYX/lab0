ДОМАШНЕЕ ЗАДАНИЕ
Условие задачи:
Клиент внес в банк R рублей. Каждый месяц эта сумма увеличивается на W процентов.
сколько будет у клиента денег через два месяца, три месяца, через полгода?
Алгоритм
1. Начало.
2. Исходные данные: R = 10000.0 ; W = 5.0
3. Вычислить коэфицент роста: K = 1 + W / 100.0
4. Вычислить сумму за месяца:
mes1 = R * K
mes2 = mes1 * K
mes3 = mes2 * K
mes4 = mes3 * K
mes5 = mes4 * K
mes6 = mes5 * K
5. Вывести результат расчетов: mes2, mes3, mes6
6. Конец
